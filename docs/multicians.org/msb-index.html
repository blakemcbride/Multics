Multics Staff Bulletins Index

Multics Staff Bulletins (MSBs) were development white papers produced by project members and circulated to the development team. As Jerry Saltzer says in MSB-001, "the MSB stream should be used only for documents which contain project planning information or are completely worthless to an outsider."

(July 2018) 83 MSBs scanned by the Multics History Project have been added to the website and linked from this index.
